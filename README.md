# Portfólio Profissional - Engenheiro de Software

Um portfólio moderno e interativo desenvolvido com React, TypeScript, GSAP e Tailwind CSS, seguindo as melhores práticas de arquitetura de software.

## 🚀 Características

- **Design Moderno**: Interface elegante com tema escuro e acentos em verde ciano
- **Animações Fluidas**: Animações suaves usando GSAP para uma experiência premium
- **Totalmente Responsivo**: Otimizado para todos os dispositivos (mobile, tablet, desktop)
- **Performance Otimizada**: Carregamento rápido e transições suaves
- **Arquitetura Escalável**: Estrutura baseada em Atomic Design e Feature-Based
- **TypeScript**: Tipagem forte para maior segurança e manutenibilidade

## 📁 Estrutura do Projeto

```
src/
├── components/
│   ├── layout/          # Componentes de layout (Header, Footer)
│   ├── sections/        # Seções da página (Hero, About, Tech, etc)
│   └── ui/              # Componentes UI reutilizáveis
├── pages/               # Páginas da aplicação
├── hooks/               # Custom React Hooks
├── lib/                 # Utilitários e configurações
├── data/                # Dados mockados
├── types/               # Definições TypeScript
└── styles/              # Estilos globais
```

## 🛠️ Tecnologias Utilizadas

- **React 18** - Biblioteca UI
- **TypeScript** - Superset JavaScript tipado
- **Vite** - Build tool e dev server
- **GSAP** - Biblioteca de animações profissionais
- **Tailwind CSS** - Framework CSS utility-first
- **Radix UI** - Componentes primitivos acessíveis
- **Lucide React** - Ícones modernos

## ⚡ Performance

- Lazy loading de imagens

- Animações otimizadas com GSAP
- CSS otimizado com Tailwind

## 🎯 Boas Práticas Implementadas

- **Atomic Design**: Componentes organizados em atoms, molecules e organisms
- **Single Responsibility**: Cada componente tem uma única responsabilidade
- **DRY**: Código reutilizável e sem repetições
- **Accessibility**: Componentes acessíveis com Radix UI
- **Type Safety**: TypeScript em todo o projeto
- **Custom Hooks**: Lógica reutilizável encapsulada

## 🚀 Como Executar

1. Clone ou baixe o repositório
2. Instale as dependências: `npm install`
3. Execute o projeto: `npm run dev`
